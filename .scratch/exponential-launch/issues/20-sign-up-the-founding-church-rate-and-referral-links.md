# 20 - Sign-up: the Exponential special offer and referral links

**What to build:** The booth QR link that opens sign-up with `EXPO26` applied, the code typed at sign-up, and `/r/<code>` referral links.

**Blocked by:** 18

**Status:** needs-info

## The rule

- The QR link opens `app.trydiscipler.com/signup` with `EXPO26` applied, and the Exponential special offer is named on every sign-up page.
- The code can also be typed at sign-up.
- After the end of 2026-12-11 Pacific the code is refused with "That code has expired, but your free trial still applies.".
- `trydiscipler.com/r/<code>` redirects to sign-up with the referral code; the landing says only that the church was invited and its first paid month is free, naming the inviter only if the inviter opted in.
- An unknown referral code shows the same page and attaches nothing.
- A referral code and `EXPO26` together apply only the Exponential special offer, and the inviting church still earns its credit.

## Acceptance

- Scanning the QR code on a phone reaches sign-up with the rate shown.
- A typed lowercase `expo26` works.
- An unknown `/r/` code cannot be told from a valid one by its page.

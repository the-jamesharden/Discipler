# 24 - Search

**What to build:** A search directory, opened with ⌘K, with `/`, or by clicking a search bar.

**Blocked by:** 23

**Status:** needs-info

## The rule

- It lists pages: the tabs, each Settings section, Intake forms, the Help pages, Account, Refer and Billing.
- It lists people, relationships and Materials by name.
- It never searches reply text or Concerns.
- It reads through RLS like every page, so an Admin finds only their own church.
- The search bar's look is chosen from the variants in mock-up 2.

## Acceptance

- ⌘K and `/` open it from any Admin page, except while typing in a field.
- Typing a person's name finds them; typing a Concern's words finds nothing.
- An Admin of one church never sees another church's names.
